02 · Unsupervised Learning / Machine Learning

Heart Disease Clustering & Anomaly Detection

An academic machine learning project focused on identifying distinct patient groups and unusual clinical profiles using unsupervised learning. The focus is on the data science process — not on medical conclusions.

Methods

  • Elbow method — choosing a sensible number of clusters.
  • K-Means & DBSCAN — two different ways of grouping patients.
  • Silhouette analysis — checking how well-separated the clusters are.
  • Isolation Forest — flagging profiles that don't fit the usual patterns.
